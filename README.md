# 📊 Business Intelligence & Reporting Templates

Welcome to the **Templates** repository by **Michal Zapletal**. This repository hosts a curated collection of production-grade, executive reporting templates, paginated dashboards, and data architecture patterns for Microsoft SQL Server Reporting Services (SSRS), Power BI Report Server (PBIRS), and the broader Microsoft BI stack.

## 🌟 Highlights & Features

- **Decoupled Architecture**: Real-world patterns (e.g., joining goals and performance without rigid database-level joins).
- **Turnkey Setup**: Every template includes automated mock/sample data scripts (\.sql\) for instant local testing.
- **Enterprise-Ready Aesthetics**: Styled with consistent palettes, modern typography, and intuitive visual cues.
